# Виджет банковских операций

Проект предназначен для маскирования, фильтрации и сортировки данных по банковским операциям клиентов.

## Основной функционал

- **Модуль widget**: содержит функции маскирования номеров карт/счетов и форматирования дат.
- **Модуль processing**: выполняет фильтрацию транзакций по их статусу и сортировку по дате.
- **Модуль masks**: базовые алгоритмы маскирования банковских данных.

## Тестирование

Проект полностью покрыт автоматическими тестами с использованием библиотеки `pytest`.
- Покрытие кода тестами (тест-каверидж) составляет **100%**.
- Реализованы параметризованные тесты для проверки различных форматов карт, счетов и дат.
- Написаны тесты для проверки обработки ошибок (`ValueError`) при передаче некорректных данных.

Для запуска тестов и генерации отчета о покрытии выполните команду в терминале:
```bash
poetry run pytest --cov=src --cov-report=term-missing
```

## Установка и запуск

1. Убедитесь, что у вас установлен Poetry.
2. Установите зависимости проекта:
   ```bash
   poetry install
   ```
3. Для демонстрации работы запустите файл `main.py`:
   ```bash
   python main.py
   ```
