# Виджет банковских операций

Проект предназначен для маскирования, фильтрации, сортировки данных, логирования и конвертации валют в финансовых транзакциях клиентов.

## Основной функционал

- **Модуль widget**: функции маскирования номеров карт/счетов и форматирования дат.
- **Модуль processing**: фильтрация транзакций по их статусу и сортировка по дате.
- **Модуль masks**: базовые алгоритмы маскирования банковских данных с логированием событий.
- **Модуль generators**: эффективная потоковая обработка больших массивов данных.
- **Модуль decorators**: декоратор `@log` для автоматического логирования работы функций.
- **Модуль utils**: чтение финансовых транзакций из внешних файлов формата JSON с логированием процесса.
- **Модуль external_api**: обращение к внешнему API Marketstack для получения текущего курса валют и конвертации сумм операций из USD/EUR в рубли.

## Логирование

В проекте реализовано сквозное логирование для модулей `masks` и `utils` с использованием стандартной библиотеки `logging`.
- Логи записываются в файлы с расширением `.log` в папку `logs` в корне проекта (`logs/masks.log` и `logs/utils.log`).
- Формат записи логов включает: метку времени, название модуля, уровень серьезности (DEBUG/INFO/ERROR) и сообщение.
- Логи перезаписываются при каждом новом запуске приложения (режим `mode="w"`).
- Ошибочные случаи логируются с уровнем `ERROR`.

## Безопасность

Чувствительные данные (ключи доступа к API) скрыты в переменных окружения с использованием файла `.env` и библиотеки `python-dotenv`. В репозитории размещен шаблон конфигурации `.env.template`. Папка с автоматическими логами `logs/` добавлена в `.gitignore`.

## Тестирование

Проект полностью покрыт автоматическими тестами с использованием библиотеки `pytest` и инструментов мокирования (`Mock`, `patch`) для изоляции сетевых запросов.
- Покрытие функционального кода тестами составляет более **80%**.

Для запуска тестов и генерации HTML-отчета о покрытии выполните команду в терминале:
```bash
poetry run pytest --cov=src --cov-report=html
```
