# Виджет банковских операций

Проект предназначен для маскирования, фильтрации, сортировки данных, логирования, а также чтения, регулярного поиска, генерации Excel-отчетов и конвертации валют в финансовых транзакциях клиентов из различных источников (JSON, CSV, Excel).

## Основной функционал

- **Модуль main**: главный модуль запуска приложения. Связывает все компоненты и предоставляет демонстрацию генерации JSON для веб-страниц, умного поиска и аналитических отчетов.
- **Модуль views**: генерация аналитических JSON-данных для Главной страницы (расчет общих расходов по картам, вычисление кэшбэка и приветствие пользователя по времени суток).
- **Модуль services**: сервис умного поиска транзакций по подстроке в полях описания и категорий, нечувствительный к регистру.
- **Модуль reports**: аналитический отчет «Траты по категории», фильтрующий транзакции за последние 3 месяца от заданной даты.
- **Модуль file_readers**: считывание финансовых операций из файлов форматов CSV и Excel (XLSX) с помощью библиотеки `pandas`.
- **Модуль widget**: функции маскирования номеров карт/счетов и форматирования дат.
- **Модуль processing**: фильтрация транзакций по их статусу и сортировка по дате.
- **Модуль masks**: базовые алгоритмы маскирования банковских данных с логированием событий.
- **Модуль generators**: эффективная потоковая обработка больших массивов данных.
- **Модуль decorators**: декоратор `@log` для автоматического логирования функций.
- **Модуль utils**: чтение транзакций из JSON и Excel, а также функции поиска по регулярным выражениям и подсчета категорий транзакций.
- **Модуль external_api**: обращение к внешнему API Marketstack для получения текущего курса валют и конвертации сумм операций из USD/EUR в рубли.

## Безопасность

Чувствительные данные (ключи доступа к API) скрыты в переменных окружения с использованием файла `.env` и библиотеки `python-dotenv`. В репозитории размещен шаблон конфигурации `.env.template`. Автоматически генерируемая папка с логами `logs/` добавлена в `.gitignore`.

## Тестирование

Проект полностью покрыт автоматическими тестами с использованием библиотеки `pytest` и инструментов мокирования (`Mock`, `patch`) для изоляции сетевых запросов.
- Покрытие функционального кода тестами составляет более **80%**.

Для запуска тестов и генерации HTML-отчета о покрытии выполните команду в терминале:
```bash
poetry run pytest --cov=src --cov-report=html
```

## Примеры запуска программы

Для запуска демонстрации всех функций курсовой работы выполните команду:
```bash
poetry run python -m src.main
```
