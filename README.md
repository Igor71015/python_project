# Виджет банковских операций

Проект предназначен для маскирования, фильтрации, сортировки данных и логирования банковских операций клиентов.

## Основной функционал

- **Модуль widget**: функции маскирования номеров карт/счетов и форматирования дат.
- **Модуль processing**: фильтрация транзакций по их статусу и сортировка по дате.
- **Модуль masks**: базовые алгоритмы маскирования банковских данных.
- **Модуль generators**: эффективная потоковая обработка больших массивов данных (фильтрация по валюте, генерация описаний и номеров карт).
- **Модуль decorators**: содержит универсальный декоратор `@log`, который автоматически записывает детали выполнения функций, входные параметры, результаты или возникшие ошибки.

## Тестирование

Проект полностью покрыт автоматическими тестами с использованием библиотеки `pytest`.
- Покрытие функционального кода тестами (тест-каверидж) составляет более **80%**.
- Реализованы параметризованные тесты для проверки различных сценариев работы функций и декоратора, включая перехват консольного вывода фикстурой `capsys`.

Для запуска тестов и генерации HTML-отчета о покрытии выполните команду в терминале:
```bash
poetry run pytest --cov=src --cov-report=html
```

## Примеры использования декоратора

```text
from src.decorators import log

@log(filename="mylog.txt")
def my_function(x, y):
    return x + y

my_function(1, 2)
```
