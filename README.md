# Виджет банковских операций

Проект предназначен для маскирования, фильтрации, сортировки данных, логирования, а также чтения и конвертации валют в финансовых транзакциях клиентов из различных источников.

## Основной функционал

- **Модуль widget**: функции маскирования номеров карт/счетов и форматирования дат.
- **Модуль processing**: фильтрация транзакций по их статусу и сортировка по дате.
- **Модуль masks**: базовые алгоритмы маскирования банковских данных с логированием событий.
- **Модуль generators**: эффективная потоковая обработка больших массивов данных.
- **Модуль decorators**: декоратор `@log` для автоматического логирования работы функций.
- **Модуль utils**: чтение финансовых транзакций из файлов формата JSON с логированием процесса.
- **Модуль external_api**: обращение к внешнему API Marketstack для конвертации сумм операций из USD/EUR в рубли.
- **Модуль file_readers**: считывание финансовых операций из файлов форматов **CSV** и **Excel (XLSX)** с помощью библиотеки `pandas` и приведение их к стандартному виду проекта.

## Безопасность

Чувствительные данные (ключи доступа к API) скрыты в переменных окружения с использованием файла `.env` и библиотеки `python-dotenv`. В репозитории размещен шаблон конфигурации `.env.template`.

## Тестирование

Проект полностью покрыт автоматическими тестами с использованием библиотеки `pytest` и инструментов мокирования (`Mock`, `patch`) для изоляции сетевых запросов и файловых операций.
- Покрытие функционального кода тестами составляет более **80%**.

Для запуска тестов и генерации HTML-отчета о покрытии выполните команду в терминале:
```bash
poetry run pytest --cov=src --cov-report=html
```

## Примеры использования новых модулей

```python
from src.file_readers import read_csv_file, read_excel_file

# Считывание операций из CSV-файла
csv_transactions = read_csv_file("data/transactions.csv")

# Считывание операций из Excel-файла
excel_transactions = read_excel_file("data/transactions_excel.xlsx")
```
